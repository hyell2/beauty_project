# 딜레이더 (개인 프로젝트)

지그재그·뷰티컬리의 **뷰티 이벤트 혜택**(쿠폰 %, 기간, 할인 상품)을 한 화면에서 비교하는 개인 프로젝트입니다.

## 사이트 보는 법
1. 이 페이지의 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. `zigzag-compare/index.html`을 더블클릭하면 브라우저에서 열립니다. (설치 필요 없음)

## 구성
| 폴더 | 내용 |
|---|---|
| `zigzag-compare/` | 비교 사이트 (HTML/CSS/JS, `data.js`·`kurly.js`에 수집 데이터) |
| `zigzag-scraper/` | 수집 스크립트 (`scrape.py` 지그재그, `kurly.py` 뷰티컬리, `history.py` 가격 기록) |
| `zigzag-scraper/output/` | 수집 결과 엑셀·CSV, 가격 기록 (저장소에는 올리지 않음, 스크립트 실행 시 생성) |

## 참고
- 각 사이트의 공개 페이지 정보를 개인 학습 목적으로 정리한 것입니다. 실제 가격·쿠폰 조건은 각 상품 페이지에서 확인하세요.
- 표시 가격은 쿠폰이 적용된 최종 혜택가이며, 개인 쿠폰·카드 할인은 포함되지 않습니다.
